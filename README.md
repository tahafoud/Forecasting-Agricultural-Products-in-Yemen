# نظام التوصية بالمحاصيل الزراعية

مشروع تعلم آلي يقدّر المحصول الأنسب للزراعة اعتمادًا على خصائص التربة والظروف البيئية المدخلة. يتضمن المشروع نموذجًا مدرّبًا وواجهة تفاعلية مبنية باستخدام Streamlit.

## المشكلة التي يعالجها المشروع

اختيار المحصول الملائم للتربة والمناخ قرار مهم؛ فالاختيار غير المناسب قد يقلل فرص نجاح الزراعة. يقدّم هذا المشروع توصية أولية بمحصول من المحاصيل التي تعلّم عليها النموذج، اعتمادًا على قيم العناصر الغذائية ودرجة الحرارة والرطوبة ودرجة حموضة التربة ومعدل هطول الأمطار.

## أهداف المشروع

- بناء نموذج تصنيف يتنبأ بالمحصول المناسب من مجموعة من بيانات التربة والطقس.
- إعداد البيانات وتحجيم الخصائص وترميز أسماء المحاصيل لتدريب النموذج.
- تقييم عدة خوارزميات تصنيف في دفتر Jupyter، واستخدام نموذج **Gradient Boosting Classifier** في التطبيق.
- توفير واجهة سهلة لإدخال القيم وعرض اسم المحصول المتوقع.

## آلية العمل

تستقبل الواجهة سبع قيم، ثم تطبق أداة التحجيم المحفوظة على المدخلات، ويمررها النموذج المدرّب للتنبؤ. بعد ذلك يحوّل مرمّز الفئات نتيجة النموذج إلى اسم المحصول ويعرضها للمستخدم.

### المدخلات

| القيمة      | الوصف                            |
| ----------- | -------------------------------- |
| N           | قيمة النيتروجين في بيانات التربة |
| P           | قيمة الفوسفور في بيانات التربة   |
| K           | قيمة البوتاسيوم في بيانات التربة |
| Temperature | درجة الحرارة (°C)                |
| Humidity    | الرطوبة (%)                      |
| Soil pH     | درجة حموضة التربة                |
| Rainfall    | قيمة هطول الأمطار (mm)           |

### المخرجات

اسم المحصول الذي يرجّح النموذج ملاءمته للقيم المدخلة.

## محتويات المشروع

```text
crop-recommendation-main/
├── code/
│   ├── app.py
│   └── Train, Testing, Saving Models Code.ipynb
├── data/
│   └── Crop_recommendation.csv
├── outputs/
│   ├── encoder.pkl
│   ├── model_gbc.pkl
│   └── scaler.pkl
├── yemen.png
└── README.md
```

- `data/Crop_recommendation.csv`: بيانات التدريب المستخدمة في المشروع.
- `code/Train, Testing, Saving Models Code.ipynb`: دفتر التدريب والتقييم وحفظ الأدوات والنموذج.
- `outputs/`: النموذج المدرّب، ومقياس الخصائص، ومرمّز أسماء المحاصيل التي يستخدمها التطبيق.
- `code/app.py`: واجهة Streamlit ودالة التنبؤ.
- `yemen.png`: الصورة التي تعرضها الواجهة.

## تشغيل التطبيق

نفّذ الأوامر التالية من مجلد المشروع في Windows:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install streamlit pandas scikit-learn==1.9.1
python -m streamlit run code/app.py
```

بعد التشغيل، افتح رابط التطبيق المحلي الذي يظهر في نافذة الأوامر. يجب تشغيل الأمر من مجلد المشروع الرئيسي حتى يتمكن التطبيق من العثور على ملفات `outputs/` والصورة `yemen.png`.

## إعادة تدريب النموذج

افتح `code/Train, Testing, Saving Models Code.ipynb` وشغّل الخلايا بالترتيب. إذا شغّلت الدفتر من جهاز أو مسار مختلف، حدّث مسار ملف البيانات في خلية قراءة CSV إلى المسار المحلي لملف `data/Crop_recommendation.csv`. تأكد أيضًا من حفظ ملفات النموذج والمقياس والمرمّز في المسارات التي يتوقعها التطبيق داخل `outputs/`.

## حدود الاستخدام

التوصية ناتجة عن نموذج تعلّم من البيانات المتاحة في هذا المشروع، وليست ضمانًا لنجاح المحصول أو بديلًا عن تحليل التربة أو استشارة مختص زراعي. لا يفترض المشروع أن البيانات تمثل جميع مناطق اليمن أو الظروف المحلية؛ ينبغي التحقق من مصدر البيانات وملاءمتها للمنطقة قبل اتخاذ قرارات زراعية.
